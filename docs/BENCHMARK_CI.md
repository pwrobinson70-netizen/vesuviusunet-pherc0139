# Benchmark with confidence intervals (192^3, 20 seeds)

Generated by `tools/benchmark_ci/summarise.py` from `tools/benchmark_ci/results/runs.csv` (written by `run.py`). Measurement only: the tools run at their current defaults; nothing is tuned. CI = 95% percentile bootstrap of the mean over seeds (1000 resamples, rng seed 0). The seeds are phantom seeds: the CI says how much a quoted number moves with the random phantom (texture, warp, wobble), not how a real scroll behaves.

## Flags: CI crosses a pass threshold

None: no CI of the mean contains the threshold it is judged against (only the spacing clean fractions have a numeric auditor threshold).

Single runs on the wrong side of that threshold (true pairs should be >= 0.8, bad pairs below it):

- Spacing clean fraction, true pairs, crushed: 1 of 20 runs (lowest 0.748).

## Metrics

- `switch_recall_trace_height`: Switch recall (trace x height). fraction of (bad trace, height) with the planted switch found.
- `false_switches_true_turns`: False switches on true turns. count per phantom (4 true turns); expected 0.
- `false_switches_bad_traces`: Spurious switches on bad traces. count per phantom (3 bad traces) besides the planted ones.
- `switch_median_col_error`: Switch column error (median). columns, found switches.
- `centre_mean_err`: Centre error, mean. voxels, umbilicus_finder vs exact centre line.
- `centre_max_err`: Centre error, max. voxels.
- `clean_true`: Spacing clean fraction, true pairs. mean over the 3 true adjacent pairs; auditor PASS needs >= 0.8.
- `clean_shared`: Spacing clean fraction, shared sheet. bad pair; auditor FAILs below 0.8.
- `clean_skipped`: Spacing clean fraction, skipped sheet. bad pair; auditor FAILs below 0.8.
- `clean_offsheet`: Spacing clean fraction, off-sheet. bad pair; auditor FAILs below 0.8.
- `aud_true_pass_rate`: Auditor: PASS rate on true traces. 7 true audits per phantom.
- `aud_bad_fail_rate`: Auditor: FAIL rate on bad traces. 6 bad audits per phantom.
- `aud_bad_fail_rate_pairs`: Auditor: FAIL rate, wrong-sheet pairs. 3 pair audits per phantom.
- `aud_bad_fail_rate_switches`: Auditor: FAIL rate, planted switches. 3 switch audits per phantom.
- `tr_on_turn_before_mean`: Tracer: points on the seed's turn. fraction, mean of 3 seeds, before repair.
- `tr_on_turn_after_mean`: Tracer: points on the seed's turn, repaired. fraction, after trace_repair where the audit FAILed.
- `tr_pass_before_rate`: Tracer: auditor PASS rate. of 3 patches, before repair.
- `tr_pass_after_rate`: Tracer: auditor PASS rate, repaired. of 3 patches, after repair.

Plots: `docs/benchmark_ci/<metric>.png` (box plot with one point per seed).
